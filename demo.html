Backend connection checklist

Requirements for live publishing

GitHub Pages provides static hosting. A secure backend must handle the OAuth callback, tokens, and publishing requests without exposing the Client Secret in JavaScript.

  • Registered OAuth authorization URL and Redirect URI
  • Backend exchanges the authorization code for an access token
  • Server-side Content Posting API request using the access token
  • Display the actual status returned by the publishing status endpoint
